# Work plans

Plans describe how a bounded piece of work will be carried out. They are useful
for efforts that span multiple steps or sessions. Small, obvious changes do not
need a plan.

No work plans are active yet.

When a plan is needed, create `YYYY-MM-DD-short-title.md` in this directory and
include:

- the outcome and explicit non-goals;
- known inputs, constraints, and relevant decision records;
- ordered, verifiable steps;
- validation and completion criteria;
- current status and unresolved blockers.

A plan may execute an accepted decision, but it must not silently create one.
Update the plan while work is active; when finished, mark its outcome and keep
it only if it remains useful project history.
